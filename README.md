# ViteConvert

A full-stack web application that converts YouTube videos into downloadable MP3 or MP4 files.

## Features

- Paste a YouTube URL
- Convert to MP3 or MP4
- Automatic file download
- Real-time progress bar
- Clean and responsive dark-themed interface
- Error handling for invalid URLs or failed downloads
- Automatic cleanup of temporary files after each conversion

### How to use
- Run the start-viteconvert.command
- Runs it locally on your computer
